# 🎬 CineAI

CineAI is a personal web project built from my passion for both cinema and software development.

I’m currently an IT student and an intern at Accenture, and I created this project to improve my practical skills in full-stack web development while building something connected to one of my biggest interests: movies.

The goal of CineAI is to provide a modern cinematic experience for discovering films using the TMDB API, with a clean UI, dynamic content, and a scalable backend architecture.

---

## 🔐 Security & Backend Architecture

Unlike many beginner movie projects, CineAI does not expose API keys in the frontend.

All TMDB requests are securely proxied through an Express backend with:

* API request validation
* CORS protection
* Rate limiting
* Environment variables
* Hidden API credentials
